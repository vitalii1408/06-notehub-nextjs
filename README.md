# NoteHub — Migration to Next.js

NoteHub notes app migrated from React + Vite to Next.js App Router with server-side data fetching and dynamic routes.

## 🔗 Links

- **Live Demo:** [https://06-notehub-nextjs-11-644c.vercel.app](https://06-notehub-nextjs-11-644c.vercel.app)
- **Source code:** [github.com/vitalii1408/06-notehub-nextjs](https://github.com/vitalii1408/06-notehub-nextjs)

## 🛠 Tech Stack

- Next.js (App Router)
- React
- TypeScript
- TanStack Query
- Axios
- Formik
- Yup
- CSS Modules

## ✨ Features

- Notes list with search and pagination
- Dynamic route for note details `/notes/[id]`
- Server prefetching and hydration with TanStack Query
- Create and delete notes in a modal form (Formik + Yup)
- Loading and error boundaries

## 🚀 Getting Started

```bash
git clone https://github.com/vitalii1408/06-notehub-nextjs.git
cd 06-notehub-nextjs
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
